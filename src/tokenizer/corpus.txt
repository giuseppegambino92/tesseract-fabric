A distributed inference engine splits a large language model across several machines: each node holds a shard of the layers or of the experts, and the activations travel between them over the network. The engine streams tokens to the client as soon as they are verified, so the user sees the answer appear word by word.

Speculative decoding drafts several tokens with a small, cheap model and verifies them with the large model in a single batched pass. When the draft agrees with the target, many tokens are accepted at once; when it disagrees, the target's own token is used instead, so the output distribution is exactly the same as ordinary decoding. The acceptance rate depends on how predictable the text is.

Memory bandwidth, not arithmetic, limits single-stream decoding: every generated token must read every active weight once. Quantized weights reduce the bytes read per token. An 8-bit block format stores thirty-two weights with one half-precision scale; a 4-bit format halves that again. The kernels multiply integer blocks and scale the result, so the weights never need to be expanded to full precision in memory.

In questa sezione descriviamo il motore di inferenza distribuita. Il modello viene diviso tra più computer: ogni nodo calcola una parte degli strati e invia le attivazioni al nodo successivo. La qualità della risposta non cambia, perché la verifica speculativa è esatta. Perché è importante? Perché così è possibile eseguire modelli più grandi della memoria di un singolo dispositivo, con più velocità e meno latenza. È una città, è un caffè, è già così: però, perché, più, può, là, giù.

Le reti locali e Tailscale permettono ai nodi di scoprirsi automaticamente: ogni nodo invia un segnale periodico con le proprie caratteristiche, e il coordinatore misura la latenza e la banda di ogni collegamento prima di assegnare i ruoli.

def softmax(x):
    m = max(x)
    e = [math.exp(v - m) for v in x]
    s = sum(e)
    return [v / s for v in e]

for i in range(10):
    print(i, softmax([1.0, 2.0, 3.0]))
